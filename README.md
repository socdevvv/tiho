# ТИХО

Комната спокойных звуков для сна, чтения и фокуса. Пять слоёв генерируются прямо в браузере, без аудиофайлов и внешних сервисов.

## Что внутри

- дождь, ветер, огонь, волны и тёплый гул;
- независимая громкость и включение каждого слоя;
- пресеты «дождь», «камин» и «ночь»;
- таймер сна на 15–60 минут с плавным затуханием;
- общая громкость, часы МСК и сохранение микса в `localStorage`;
- PWA: можно установить на телефон и открыть офлайн.

## Запуск

Открой `index.html` в браузере. Для работы звука нужен первый клик — это ограничение браузеров, а не приложения.

## Стек

Чистые HTML, CSS и JavaScript. Звук синтезируется через Web Audio API.
